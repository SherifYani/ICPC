# ICPC ANU Level 0 Portal - User Guide

## Website Overview

**Purpose:** A modern, interactive learning platform for ICPC ANU Community Level 0 students to access weekly programming lessons, video tutorials, practice problems, and resources.

**Access:** Public - No login required

---

## Powered by Manus

This portal is built with cutting-edge web technologies:

- **Frontend:** React 19 + TypeScript + Tailwind CSS 4 with shadcn/ui components
- **Rendering:** React Markdown for dynamic content processing
- **Animations:** Framer Motion for smooth, engaging transitions
- **Styling:** Custom CSS with ICPC ANU brand colors (Teal #5CC8D1 & Yellow #FFC107)
- **Theme System:** Dark/Light mode with localStorage persistence
- **Deployment:** Auto-scaling infrastructure with global CDN for fast, reliable access

---

## Using Your Website

### 1. Explore Weekly Modules

The portal displays five weeks of C++ programming content:

- Click on any week card (e.g., "🚀 Week 01 - Fundamentals of C++ Programming") to expand it
- The card smoothly opens to reveal comprehensive content including lectures, resources, and practice problems
- Each section includes markdown-rendered content with properly formatted headings, links, and tables

### 2. Access Learning Resources

Once a week is expanded, you'll find:

- **📚 Key Resources:** Tables with links to video lectures, slides, and tutorials
- **🎥 Lecture Sessions:** Recording links and code solutions
- **📄 Practice Sheets:** Links to CodeForces problem sets with problems A through H
- **📖 Additional Resources:** Supplementary videos on advanced topics
- **🌐 Connect with Us:** Social media links to Facebook and YouTube

All external links open in new tabs for seamless browsing.

### 3. Switch Between Light and Dark Modes

Click the "🌙" (Moon) or "☀️" (Sun) icon in the top-right navbar to toggle between themes:

- **Light Mode:** Clean, bright interface perfect for daytime learning
- **Dark Mode:** Easy on the eyes for evening study sessions
- Your preference is automatically saved and restored on your next visit

### 4. Navigate Smoothly

- **Navbar:** Sticky header with ICPC ANU branding and theme toggle
- **Scroll-to-Top Button:** Appears after scrolling down; click to jump back to the top
- **Smooth Scrolling:** All page transitions and animations are fluid and responsive
- **Mobile-Friendly:** Fully responsive design works perfectly on phones, tablets, and desktops

## Managing Your Website

### Settings & Customization

Access the Management UI (right panel) to:

- **Dashboard:** Monitor website analytics and performance
- **Settings:** Customize website name, logo, and visibility
- **Domains:** Bind custom domains or use the auto-generated domain
- **Database:** Manage content and user data (if applicable)
- **Secrets:** Securely store API keys and environment variables

### Updating Content

To modify week content or add new modules:

1. Edit the markdown files in your GitHub Wiki
2. The portal fetches content directly from GitHub, so changes appear automatically
3. No deployment needed—updates are live immediately
